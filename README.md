# Jarvis
Assistente pessoal privado, operado via Telegram, de uso exclusivo do próprio autor. Não é um produto público e não aceita cadastro de outros usuários.

O que o Jarvis faz
Responde perguntas por mensagem no Telegram, usando a API da Anthropic (Claude)
Busca informações atuais na internet quando a pergunta exige
Consulta e cria eventos na Google Agenda do autor
Lê e envia e-mails pela conta Gmail do autor
Acesso

O acesso é restrito a uma única conta do Telegram, definida em configuração. Qualquer outra pessoa que tente usar o bot recebe uma recusa automática.
